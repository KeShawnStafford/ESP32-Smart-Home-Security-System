# ESP32-Smart-Home-Security-System
Overview

A microcontroller-based home security system developed as my senior capstone project at Middle Tennessee State University in 2026.

The project integrates physical sensors, keypad authentication, Wi-Fi connectivity, and remote monitoring into a functioning security prototype.

Technologies Used

ESP32-WROOM-32 and ESP32-CAM

C++ and Arduino IDE

PIR motion sensor and magnetic reed switches

4×4 keypad, buzzer, and LEDs

Wi-Fi-based web interface

Key Features

Armed Away and Armed Stay modes

PIN-based keypad authentication

Door and motion detection

Exit-delay countdown

Remote arm/disarm through a web interface

Real-time zone monitoring

Email alerts for security events

Live camera streaming

Development and Troubleshooting

During development, I tested sensor behavior, corrected keypad mappings, resolved firmware compilation errors, and refined alarm logic.
